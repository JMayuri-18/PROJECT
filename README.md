# Student Registration Form

A static student registration form built using **HTML** and **CSS**. This project shows how to build a clean, well-structured form layout using basic web technologies.

## Description

This is a front-end registration page for students. It includes text inputs, a split name field, a date of birth field, a mobile number field with country code, radio buttons, checkboxes, a dropdown menu, file upload, and a text area. It is made to practice HTML form elements and CSS styling. The page is static, so it does not store or process any data.

## Features

- Clean, row-based form layout styled with CSS
- Student name split into First Name and Last Name
- Date of birth entered as Day, Month, and Year (DD-MM-YYYY)
- Mobile number field with a fixed `+91` country code
- Gender selection using radio buttons
- Department selection using checkboxes
- Course selection using a dropdown menu
- Student photo upload
- Address entry using a textarea

## Tech Stack

- HTML5
- CSS3
